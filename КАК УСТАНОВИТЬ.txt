XR zapret — установка (Windows 64-bit)

1. Если Windows просит .NET Framework: запустите NDP48-x86-x64-AllOS-ENU.exe, установите .NET Framework 4.8 и перезагрузите ПК, если потребуется. Если .NET уже есть — пропустите шаг.
2. Откройте XR zapret.exe и подтвердите запрос администратора.
3. Нажмите «ВКЛЮЧИТЬ».

VPN (вкладка в настройках — шестерёнка слева вверху):
1. Откройте настройки → вкладка «VPN». Движок AmneziaWG уже встроен, ничего ставить не нужно.
2. Нажмите «ВЫБРАТЬ» и укажите ваш .conf файл (его выдаёт VPN-провайдер; своих серверов у приложения нет).
3. Нажмите «ПОДКЛЮЧИТЬ VPN». После подключения приложение само покажет новый IP.
4. По желанию включите «Подключать VPN при запуске».

Важно: не держите обход (ВКЛЮЧИТЬ) и VPN включёнными одновременно — сначала выключите одно, потом включайте другое.

Оба EXE держите в одной папке только для удобства: после установки .NET его установщик можно удалить. Других файлов для XR zapret не нужно.
